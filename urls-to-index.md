## Google Search Console Submission Steps
1. Navigate to [Google Search Console](https://search.google.com/search-console).
2. Select property `https://pdfcrop.co.in`.
3. Submit `sitemap.xml` under **Sitemaps** -> verify "Success" status.
4. Use **URL Inspection** on `https://pdfcrop.co.in`, `https://pdfcrop.co.in/blog`, and top marketplace croppers, then click **Request Indexing**.
5. Once crawled, return to [Google AdSense](https://adsense.google.com) and request site review.
